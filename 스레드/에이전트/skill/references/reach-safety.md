# 노출 보호 규칙 (2026-10-11 사용자 지시: "알고리즘에 걸리지 않게")

배경: 2026-10-11 매시 7개 체인 게시(하루 답글 33개, 그중 링크 24개, 같은 특가 문구 반복, 1~2분 사이 연속 게시) 뒤 KST 12시부터 새 글 조회수가 0~10으로 떨어졌다. 계정 상태 화면에는 제재가 없었지만, 10/6에 "대량 행동" 스팸 사유로 댓글 1건이 삭제된 이력이 있다.

## 빈도
- 본문 글(체인 1세트)은 하루 최대 3개, 직전 내 본문 글과 최소 3시간 간격. 자동·수동·릴스 교차게시를 모두 합산한다.
- 같은 시각에 여러 세트를 몰아 올리지 않는다. 체인 답글은 threads.mjs가 20~45초 간격으로 올린다.

## 링크·홍보
- 링크와 특가 CTA(`cta_mode: campaign`)는 하루 1세트(저녁 슬롯)에만 둔다.
- 나머지 세트는 `cta_mode: soft`: 마지막 글은 링크·가격·특가·무료·신청 없이 내용 정리와 댓글 질문으로 끝낸다(예: "너는 몇 번이었어?"). validate가 링크·홍보 단어를 막는다.
- campaign 세트의 CTA 문장은 매번 새로 쓴다. 필수 문구(required_cta_phrases)만 유지하고 앞뒤 문장을 직전 3개 CTA와 다르게 쓴다.

## 체인 길이
- 번호 분류 연재형은 도입 + 1~5번 + 마무리 = 최대 7개. 소재가 4갈래면 6개로 줄인다. 체인을 더 늘리지 않는다.

## 휴식
- 새 글 조회수가 계속 한 자릿수면 게시를 늘리지 말고 줄인다. 같은 문구의 댓글 답글을 대량으로 달지 않는다.
