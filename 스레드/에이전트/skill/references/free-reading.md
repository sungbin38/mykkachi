# 무료 사주풀이 모집글(글유형 12)과 댓글 답글

사용자 요청(2026-10-11): 다른 계정의 "무료 사주 봐드립니다" 글처럼, 댓글로 생년월일·고민을 받으면 돈쌤이 **댓글 11분 뒤**에 답글로 짧은 풀이를 달아준다. 컴퓨터가 꺼져도 클라우드 루틴이 처리한다. 모집글은 하루 1회.

## 1. 모집글 (format_id `12`)

- hooks.md 공식으로 시작하는 후킹 첫 줄 → 돈쌤 소개(사실만: 한국·대만 9년 상담) → 무료로 댓글 풀이 → 받을 정보 → 짧은 약속 문장. 돈쌤 반말.
- 받을 정보: `생년월일 + 태어난 시간(모르면 모름) + 양력/음력 + 성별 + 고민`. 예시 한 줄을 넣는다(가상의 생일).
- “N번째”, “조회수”, 상담 인원, 후기, 복채 금액을 지어내지 않는다. “선착순 N명”은 사용자가 정할 때만.
- 마지막 post는 다른 글과 같이 운영설정 CTA(무료 리포트 신청).
- 매번 문장을 바꾼다. 최근 모집글과 같은 후킹·문장 재사용 금지.

## 2. 답글 대상

- `node 스레드/에이전트/comments.mjs due --min-age=11` 이 돌려준 댓글만. 최근 3일 안의 format 12 글(초안 JSON의 publication)에 직접 달린 댓글 중 돈쌤이 아직 답하지 않은 것.
- 생년월일이 있는 풀이 요청에만 답한다. 응원·잡담·광고·욕설·다른 사람끼리의 대화는 건너뛴다.
- 날짜는 있는데 성별이 없으면 “성별도 알려주면 바로 봐줄게”처럼 한 줄로 되묻는다(한 번만). 양력/음력이 없으면 양력으로 보고 “양력 기준으로 봤어”라고 밝힌다. 시간이 없으면 시주 없이 본다.
- 한 실행에서 최대 15개. 남은 건 다음 실행이 이어서 처리한다.

## 3. 명식 계산 (필수)

추측으로 쓰지 않는다. 반드시 계산한다.

```sh
node 스레드/에이전트/saju-chart.mjs --date=1990-05-12 --calendar=solar --time=15:00 --gender=F
node 스레드/에이전트/saju-chart.mjs --date=1964-10-19 --calendar=lunar --gender=M   # 시간 모름
```

- 음력 윤달이면 `--leap`. 두 사람(궁합·부부·자녀운)이면 둘 다 계산.
- 출력: 사주 네 기둥과 십성, 오행 개수, 대운(시작 나이·연도·십성), 올해~2년 뒤 세운의 십성과 원국 지지와의 충·합.
- 고민 주제에 맞는 근거를 고른다: 돈=재성·식상생재·비겁, 직장·이직=관성·인성·식상, 연애·결혼=여자는 관성·남자는 재성과 일지, 공부·자격=인성, 자녀=여자 식상·남자 관성. 현재 대운과 세운의 십성·충합을 시기 근거로 쓴다.
- 계산 근거(기둥, 근거 십성, 연도)는 답글에 길게 적지 않고 기록 파일에 남긴다.

## 4. 답글 쓰기

- 500자 이내, 돈쌤 반말, 따뜻하지만 좋은 말만 하지 않는다. 생년월일을 다시 적지 않는다.
- 흐름: “사주 보니까 제일 먼저 눈에 들어오는 건 ~” (원국 특징 + 고민 연결) → “흐름상 20XX년 ~ 쪽으로 움직임이 커지는 편이야” (세운·대운 근거, `가능성`·`볼 만해`로 표현, 월 단위 확정 금지) → “의외로 ~가 중요해” (구체적 한 가지) → 마지막 한 줄: “더 자세한 시기랑 ~ 궁금하면 프로필 링크에서 무료 리포트 신청해줘”.
- 매 답글의 문장을 바꾼다. 같은 틀만 반복하지 않는다.
- 금지: 임신·출산·건강·사망·이혼의 확정, 의학적 조언, “대출 받아/투자해” 같은 재정 지시, 공포 조장, 지어낸 상담 경험. 임신·건강 고민은 “사주는 시기 흐름만 보는 거라 몸은 꼭 전문의랑 같이 챙겨”를 덧붙인다.
- 한 사람이 여러 번 물어도 답글은 댓글마다 한 번.

## 5. 게시와 기록

```sh
node 스레드/에이전트/comments.mjs reply <comment_id> <답글.txt> --execute
```

- 같은 댓글에 다시 실행하지 않는다. 오류가 나면 재실행하지 말고 `due`로 답글이 달렸는지 확인한다.
- `스레드/무료풀이/YYYY-MM-DD.jsonl`에 한 줄씩 기록: 시각, post 초안 id, comment_id, username, 사용한 기둥·근거 요약, 답글 url. 생년월일 원문은 저장하지 않는다.
