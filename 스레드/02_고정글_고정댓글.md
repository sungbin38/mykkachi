## 2. 모든 글 아래 첫 댓글 (고정 댓글)
글을 올린 직후 내 계정으로 아래 댓글을 달고, 그 댓글을 고정합니다.

### 기본형
```
사람이 직접 읽는 1:1 사주 상담은 여기서 예약할 수 있어요.
상담이 끝나면 하루 안에 약 10쪽 리포트를 이메일로 보내드립니다.
https://mykkachi.com/book?utm_source=threads&utm_medium=post
```

### 이야기형 (스토리 글, 위로 글에 사용)
```
이 글을 읽고 내 사주가 궁금해졌다면, 서두르지 않고 봐드릴게요.
시간이 걸리더라도 제대로. 그게 마이까치의 약속입니다.
https://mykkachi.com/book?utm_source=threads&utm_medium=post
```

### 리포트형 (상담 없이 리포트만 원하는 사람 대상)
```
통화가 부담스러우면 리포트만 받아볼 수도 있어요.
사연과 생년월일시를 적어주시면 상담자가 직접 읽고 PDF로 정리해 보내드립니다.
https://mykkachi.com/book?utm_source=threads&utm_medium=post
```

### 링크 규칙
- 댓글 링크는 항상 `https://mykkachi.com/book?utm_source=threads&utm_medium=post` 입니다.
- 특정 글의 반응을 따로 보고 싶으면 `&utm_content=06` 처럼 글 번호를 덧붙입니다.

## 3. 댓글 답장 톤
- 사주를 댓글에 적어 봐달라는 요청: "댓글로는 제대로 볼 수 없어서요. 예약 페이지에 사연을 남겨주시면 시간을 들여 읽어볼게요."
- 예약 전 질문이 많은 댓글: "댓글보다 카카오톡이 편하시면 여기로요. https://pf.kakao.com/_xfeQxiX/chat"
- 가격 질문: "1:1 상담은 20만 원이고, 상담 후기와 리포트 일부를 마이까치 소개에 쓰는 데 동의해주시면 15만 원이에요. 리포트만 받으시면 10만 원(동의 시 5만 원)입니다."
- 비판·불신 댓글: 논쟁하지 않고 "사주는 나를 이해하는 하나의 관점이라고 생각해요"로 짧게 마무리.
