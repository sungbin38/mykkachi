# 스레드(Threads) 콘텐츠 폴더

현재 운영 계정은 **돈쌤 @don.ssaem**입니다. 사이트와 신청 동선은 mykkachi.com을 사용합니다.

## 돈쌤 자동 작가·게시 에이전트

- “스레드 글 만들어줘”: 이전 글과 겹치지 않는 새 주제를 자동 선택하고 내용 1~2개 + 마지막 신청 댓글을 작성합니다. 유형 선택부터 묻지 않습니다.
- “이 글 올려줘”: 특정한 원고를 API로 이어 게시합니다. “만들어서 올려줘”는 작성·게시를 함께 수행합니다. 작성 요청만으로 공개 게시하지 않습니다.
- [에이전트 스킬](에이전트/skill/SKILL.md), [운영 설정](에이전트/운영설정.json), [API 사용법](에이전트/skill/references/publishing.md).
- 신규 초안은 `초안/날짜_slug.json`에 저장합니다. 최근 원고를 읽어 소재 중복을 줄이고 API 입력으로도 사용합니다. 기존 01~63번 원고는 그대로 보관합니다.
- 현재 무료 리포트 이벤트가 기본 안내입니다. Threads 팔로우·카톡 친구추가 후 웹 신청란에 완료 사실을 반드시 적으면 입금 없이 신청하며, 하루 뒤 10만원 상당 리포트를 이메일로 받습니다. 사용자의 종료·변경 지시 또는 설정된 종료 시각에 맞춰 갱신합니다.
- 실행: `bash 스레드/에이전트/실행.sh`. 모델은 기존 GPT-6-Astra/high 설정을 유지합니다.

## 폴더 규칙
```
스레드/
├── README.md            이 문서 (운영 규칙, 체크리스트)
├── 01_프로필.md         계정 이름 · 소개글 · 링크
├── 02_고정글_고정댓글.md 프로필 상단 고정 글, 글마다 다는 첫 댓글
├── 03_게시글/           올릴 글. 번호_제목.md 한 편에 한 파일
│   ├── 00_목록.md       전체 목록, 업로드 순서, 상태
│   ├── 01_운의흐름/     14~23 · 운과 변화
│   ├── 02_일과선택/     24~33 · 커리어와 적성
│   ├── 03_관계와나/     34~43 · 관계와 자기 이해
│   ├── 04_마이까치와리포트/ 44~53 · 브랜드와 서비스
│   └── 05_스레드조사기반/   54~63 · 공개 스레드 조사에서 착안
└── 참고/                외부 참고 자료 (여기 글은 그대로 쓰지 않고 소재로만 씀)
```

- 기존 형식의 Markdown 보관을 요청한 글은 `03_게시글/`의 주제별 폴더에 `번호_제목.md`로 추가하고 `00_목록.md`에 한 줄 추가합니다. 기존 01~13번은 원래 위치에 둡니다.
- 올린 글은 `00_목록.md`의 상태를 `올림 (날짜)`로 바꿉니다.
- 참고 자료는 `참고/`에만 넣습니다. 참고 글의 문장을 그대로 옮기지 않습니다.

## 초안 저장과 계정

완성 초안은 로컬 JSON으로 저장하고 대화에 표시합니다. 브라우저 임시저장은 별도 요청 시 진행하며 실제 로그인 계정이 돈쌤인지 확인합니다. 과거 Aside의 마이까치 로그인 계정을 현재 게시 대상으로 사용하지 않습니다. API는 토큰의 실제 계정을 조회하고 돈쌤 계정일 때만 게시합니다.

## 글 쓰는 기준
- 한 글 500자 이내 (스레드 제한). 각 파일 끝에 글자 수를 적어둡니다.
- 말투: 스레드 게시글과 이어지는 글·첫 댓글은 항상 자연스럽고 따뜻한 반말로 씁니다(사용자 지정). 독자에게 말을 건네듯 쓰되 과장 금지, 이모지는 글당 0~1개. 사이트·상담 안내 자체의 존댓말과는 구분합니다.
- "사람이 직접 읽는다", "시간이 걸리더라도 제대로"가 브랜드의 축입니다. 빠르다, 정확하다, 족집게 같은 말은 쓰지 않습니다.
- 운세 단정("무조건 좋아진다")은 피하고, 관점과 질문으로 끝냅니다.
- 신청 링크와 카카오 채널은 마지막 유입 댓글에 넣습니다. 본문은 링크 없이 읽히게 씁니다.
- 링크 도메인은 mykkachi.com 이고, 유입 추적을 위해 `utm_source=threads`를 꼭 붙입니다 (`?threads` 같은 임의 파라미터는 집계되지 않음). 형식은 01_프로필.md 참고.
- 자동 무료 풀이 기능과 사람이 작성하는 무료 리포트 이벤트는 구분합니다. 이벤트는 운영설정의 유효한 기간·조건을 따릅니다.

## 올리기 전 체크
1. 500자 이내인가
2. 브랜드 톤에서 벗어난 문장은 없는가 (단정, 공포 조장, 과장)
3. 최신 운영설정의 마지막 신청 댓글을 함께 달았는가
4. 발행 기록에 실제 게시물 ID·링크가 남았는가 (기존 Markdown 원고는 목록 상태도 갱신)

## 기존 50개 원고 사용법

이하와 01_프로필.md·02_고정글_고정댓글.md는 기존 마이까치 원고 자료입니다. 현재 돈쌤의 계정·톤·CTA에는 에이전트 운영설정을 우선합니다.

- [전체 목록](03_게시글/00_목록.md)에서 14~63번을 고릅니다. 다섯 폴더에 각각 10개씩 있습니다.
- 파일의 `본문`을 게시하고 `첫 댓글`을 이어 답니다. 참고 출처·상태·글자 수는 게시하지 않는 내부 메모입니다.
- 첫 댓글에는 글별 `utm_content`가 붙어 있습니다. 복사할 때 번호를 유지하면 글별 유입을 구분할 수 있습니다.
- 같은 주제만 연속으로 올리기보다 운의 흐름 → 관계와 나 → 일과 선택 → 스레드 조사 기반 → 브랜드·리포트 순으로 섞어 써도 좋습니다. 이는 편집상 제안이며 성과가 검증된 게시 순서는 아닙니다.
- 조사 기반 원고의 출처와 확인 범위는 [공개 게시물 조사](참고/2026-10-05_스레드_공개게시물_조사.md)에 따로 기록합니다. 외부 글의 반응 수치는 우리 글의 예상 성과가 아닙니다.
